# 双语互动学习板块

## 目标

`apps/web/` 新增“互动学习实验室”。用户可以在中文和英文之间切换，逐词查看：

- 词汇的有序语义过程；
- 同一关联帧内需要同时满足的局部状态；
- 语义过程的最少独立证据帧数；
- A–Z 标准资料对应的教学示意图，并与动作指导并排查看；
- 结合公开语义过程的 21 词 3D 风格动作动画；
- 参考视频的授权状态；
- 当前词汇内嵌的摄像头练习与原型评分面板，包含采集、评分、重试、下一词和成功反馈。

入口是首页的“互动学习实验室”，静态资源位于：

```text
apps/web/assets/content/interactive_learning_contracts.json
apps/web/assets/content/public_motion_template_manifest.json
apps/web/assets/content/reference_media_manifest.json
apps/web/js/interactive-learning.js
```

互动页跟随首页的全局白天/夜晚模式；Canvas 示意动画也会在切换主题后即时重绘，避免只改变网页外壳而保留夜间画布背景。

## 21 词 3D 语义动画

原 Canvas 3D 风格人物未通过视觉审核：人体比例、手型和真实动作空间关系均不足以作为教学参考。因此公开互动页已停止默认展示该人物，并回退到 2D 动作示意；3D 按钮显示“重制中”且不可点击。新版改为从私有环境中的1号三视角人工确认帧提取无脸部动作锚点，再重定向到许可清晰、经过人工审核的人形 rig。真人帧、私有 landmark 和转绘中间件不会进入公开仓库。

旧程序化 profile 和相似物叠加代码暂留作集成测试，不再宣称为合格3D模型。新版人物通过人物比例、手型、动作阶段和再识别风险审核后，才会重新启用3D入口。

该动画是前端教学示意，不是对真人动作的复原，也不作为评分模板。绘制实现位于 `apps/web/js/avatar3d.js`，不读取私人视频、真人 landmark 或用户身份数据；未来只有经过授权和发布审查的自有 3D rig 才能替换当前程序化 profile。

## 公开数据边界

当前版本有意不发布以下内容：

- 私人志愿者原始视频和切片；
- 真人 landmark preview 图片；
- 未完成人工审核、授权和脱敏审查的 landmark 缓存；
- 任何能反推出志愿者身份的编号、文件路径或元数据。

动作指导是面向学习者的公开文本，不包含用户样本标识。当前参考视频清单包含 3 个已人工审核的匿名 Avatar 自生成演示（超市、人们（人民）、跳），由 `reference_media_manifest.json` 统一管理；有合格视频的词汇在互动学习、挑战和评分参考接口中优先使用该视频，尚无合格视频的词汇才显示示意动画占位。页面不会接入真人志愿者视频。未通过人工审核的 Wan 产物仍不进入公开仓库。

将来接入视频时，应先在独立媒体清单中记录：来源、授权范围、是否自行生成、许可证、去标识化审查和发布日期；没有完整记录时保持空占位。

`public_motion_template_manifest.json` 同样先保持空模板列表，只定义与评分 API 兼容的脱敏 landmark 字段；只有通过人工审核、签名者隔离和公开发布审查的模板才能填入。

## 摄像头与评分

互动学习页直接挂载共享评分桥的摄像头面板，不再跳转到挑战页。左侧将参考示意图与动作指导组织为一个连续的大面板；右侧默认只显示词汇状态和“开始摄像头评分”入口，用户点击后只展开精简的摄像头界面，仍需再次点击界面内的“开启摄像头”才申请摄像头并开始采集。页面进入时会自动检查评分 API 并预热 Web Holistic 模型，但不会调用浏览器摄像头权限。浏览器优先使用同源 MediaPipe Holistic 提取匿名运动关键点，并通过共享评分 API 契约提交 `landmark_rows`；不上传原始视频。API 未连接时，页面显示明确标注的本地预览分。

评分达到成功门槛后，当前板块内显示成功结果、分数、评分诊断、重试和下一词按钮，并同步点亮本地学习记录与成功提示；不会把用户带回挑战页。

互动页的语言开关同时覆盖词汇指导、导航、摄像头面板、Web Holistic 状态、采集提示、评分过程、结果建议和错误/重试提示；切换语言不会改变评分数据或摄像头权限行为。

当前有 5 个新增词（鸡蛋、烤串、科学、森林、勇敢）已通过首轮正负样本工程候选门槛，互动页以“候选校准 Demo”开放摄像头试运行；由于候选 profile 仍标记为 `candidate_only_not_for_production`，公共仓库尚未携带其真人 landmark 模板，当前返回的是捕获质量/原型预览分，不宣称已经上线最终语义 DTW 评分。其余新增词仍显示“评分模板待上线”。所有分数都是教学原型分，不是认证成绩，也不用于身份识别或高风险判断。

惯用手左右适配已记录为后续工作项：后续将以主手/辅助手角色、参考示意变体和评分坐标归一化统一推进；本版本仍保持原有评分数据契约，不提前假定历史样本的惯用手。

## 部署

本板块随 `apps/web` 静态前端发布：

```bash
cd apps/web
python -m http.server 5173
```

摄像头功能需要 `localhost` 或 HTTPS。生产环境继续使用现有 GitHub Pages workflow；评分 API 需要单独部署在 HTTPS 服务上，并由 `?api=https://...` 或挑战页 API 输入框配置。
