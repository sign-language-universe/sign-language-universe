- 文档日期：2026-08-09
- 状态：已上线（纯前端 ONNX 推理，互动学习主打分模块）
- 相关：README（打分主路径）、apps/web/js/model-scoring.js、apps/web/assets/model/

## 1. 背景与目标

原打分系统为手工特征工程（237/406 维 + DTW + 人工校准权重，每词 40+ 超参数）。为降低人工校准成本、实现"语义动作级"细粒度评分，引入**轻量深度学习模型**：

- 输入：MediaPipe Holistic landmark 序列（匿名关键点，非原始视频）
- 输出：47 个核心语义动作程度分（每词 1-7 个，稀疏激活）+ 词判定（可选门控）
- 部署：纯前端（onnxruntime-web WASM），无后端依赖
- 综合分 = 目标词核心语义动作程度加权（无词判定干预）

## 2. 数据

- **正样本**：930 条受信任正样本（21 词 × 11 志愿者 × 多视角），每条含 landmark 序列 + 语义动作程度软标签
- **VL 软标签**：qwen3-vl-8b 对每条样本标注其语义动作完成程度（0-100）——本词动作打分可靠；鸡蛋/花经"手部特写双图重标注"校准（分数 +30/+12）
- **增强**：时间缩放/平移/高斯噪声（930 → 2790，仅训练用户副本防泄漏）
- **异常负例（数据飞轮）**：幅度异常/时序乱序/手部噪声 3 类破坏性增强（2790 条）+ VL 标注低分 → "离谱→低分"监督
- 特征：235 维/帧（pose 27 + 左右手 63×2 + face 36 + 左右手形 19×2 + 双手关系 8），归一化 scale=max(肩宽,躯干)
- 划分：user 01-07 训练 / user 08-09 跨人测试（159 条）

## 3. 模型架构

```
输入: landmark 序列 (1×30×235)
  ↓
BiLSTM 骨干 ×3（双向 128d，mean-pool → 256d embedding，预训练后冻结）
  ↓
语义动作头 ×47: 程度 sigmoid + 存在性 sigmoid（每词稀疏激活 1-7 个）
  ↓
综合分 = 目标词动作头程度加权（0-100）
```

- 参数量：1.19M（骨干 1.17M + 动作头 ~20K）
- 训练：AdamW lr 1e-3，cosine，batch 32，早停；损失 = MSE(程度) + 0.3×BCE(存在性)
- 关键机制：
  - **冻结骨干**：预训练词分类骨干冻结、仅训动作头（小样本下 corr 0.06 → 0.79）
  - **VL soft-label 蒸馏**：VL 分数作为连续回归目标（优于硬标签二值化）
  - **词判定门控（可选，默认关闭）**：词判定仅作诊断，不干预总分

## 4. 训练方式

| 阶段 | 内容 |
|------|------|
| P0 | 930 条 → X(930,30,235)，user1-7/8-9 划分 |
| P0b | 增强 930→2790 |
| VL 标注 | qwen3-vl-8b 逐样本标注语义动作程度（930 条） |
| P1 骨干 | BiLSTM/Transformer 21 词分类（预训练） |
| P2 动作头 | 冻结骨干 + VL 程度回归（47 头稀疏） |
| P3 评估 | 词判定 + 动作综合分 |
| P4 导出 | PyTorch → ONNX（action + word 双模型） |

两种训练思路验证：**VL soft-label 蒸馏（MSE 回归）有效（corr 0.79-0.81）**；硬标签 BCE 监督无效（corr 0.02）；不冻结骨干无效（corr 0.06）。

## 5. 效果（跨人 test user 08-09）

- **词判定（P1 骨干）**：98.11%（BiLSTM）/ 97.48%（Transformer），超 LinearSVC 基线 95.6%
- **语义动作程度**：Spearman corr 0.81 / MAE 0.061（冻结骨干 + 蒸馏 + 增强）
- **动作综合分**：mean 0.85 [0.51-0.99]；鸡蛋 0.57→0.93、花 0.76→0.87（特写重标注校准后）
- **固定词打分场景**：做对词 0.837 / 做错词 0.254（门控模式）；纯语义模式总分=composite
- **前端性能**：模型加载 ~0.6s，打分 8-45ms，纯浏览器 WASM

## 7. 已知限制与下一步

1. 动作头对"非本词样本"输出无监督偏高（分离度 0.006）——"做错词→低分"依赖词判定门控（默认关闭）或负例训练
2. VL 标注对精细手形词（虎/花）保守——手部特写重标注可校准（鸡蛋已校准）
3. 谗词"舌头舔"：骨架无舌头关键点（数据源限制）
4. 下一步：异常负例接入训练（离谱→低分）、双监督架构（词判定依赖动作头）、魔塔 Static 部署
